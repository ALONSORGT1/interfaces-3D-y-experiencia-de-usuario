# Renuncia definitiva · Boliche de oficina

Videojuego Web 3D individual para el examen de interfaces 3D y experiencia de usuario.

En desarrollo progresivo. Esta primera versión contiene la estructura HTML/CSS/JS, import map de Three.js, escena base e interfaz inicial. Servir esta carpeta por HTTP; no abrir index.html mediante file://.

## Ejecución local

Desde esta carpeta: `python -m http.server 4173 --bind 127.0.0.1`. Abrir http://127.0.0.1:4173.
